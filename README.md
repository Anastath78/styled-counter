# Счётчик с плюсом и минусом

Учебная практика, кейс-задача № 2 - простейший счётчик (counter) на HTML, CSS и ванильном JavaScript.

## Возможности

- две кнопки - «Минус» и «Плюс» - и окошко результата;
- фон страницы - линейный градиент, карточка счётчика расположена по центру окна браузера;
- у кнопок скругление углов 5 px и градиентный фон;
- нажатие обрабатывается слушателями событий (`addEventListener`): «Плюс» увеличивает значение на 1, «Минус» уменьшает на 1;
- цвет окошка результата зависит от значения: больше нуля - жёлтый, меньше нуля - зелёный, ноль - красный;
- на значении 10 кнопка «Плюс» становится неактивной, на значении -10 - кнопка «Минус»; при любом другом значении обе кнопки снова активны;
- под кнопками находится окно сообщения, в котором на значениях 10 и -10 появляется надпись «Вы достигли экстремального значения».

## Запуск

Сборка и сервер не нужны - достаточно открыть `index.html` в браузере.

## Структура

- `index.html` - разметка;
- `style.css` - стили;
- `script.js` - логика счётчика.
